# Hardware and capture notes

The hardware module documents a low-cost, adjustable phone-to-eyepiece adapter and repeatable bright-field capture setup. It does not include CAD, device measurements, or a validated capture profile.

See docs/HARDWARE_CAPTURE_PROTOCOL.md for setup and failure observations. Keep a record of the phone, camera lens, microscope, objective, eyepiece, adapter version, capture settings, and authorized material. Store private captures outside Git.
